# CamGO - Cho thuê đồ cắm trại
**Website** cho ***thuê đồ cắm trại***
| Thư mục | Nội dung |
|:---:|:---:|
|docs|Tài liệu bàn giao|
|data|Bảng tính đơn thuê|
|logs|Log truy cập website|
```Bash
pwd
Ls -Force -Recurse
mv .\quy_dinh_thue.txt .\docs\
mkdir backup
cp .\data\don_thue_thang_5.xlsx .\backup\
rm .\temp_505.tmp
cd .\logs\; ls; cd..
```
